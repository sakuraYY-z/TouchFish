## 2. 项目结构

```text                    /history   查看当前设备会话的本地聊天记录
                         /pull      主动拉取离线消息
                          /reset     删除当前会话 session
MiniSignal/
  local-server/
    server.ts        # WebSocket 本地服务器
    users.ts         # 在线用户和设备管理
    relay.ts         # 消息转发和离线队列

  demo-client/
    client.ts        # 命令行聊天客户端
    crypto/          # AES-GCM 加密解密
    identity/        # 身份密钥生成和保存
    prekey/          # SignedPreKey / OneTimePreKey
    session/         # X3DH 和会话状态
    message/         # 本地消息历史保存
    storage/         # 本地生成的数据文件
